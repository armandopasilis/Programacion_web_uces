## Introducción

El presente proyecto consiste en el desarrollo progresivo de una aplicación web que simula el funcionamiento básico de un e-commerce, implementada a lo largo de la cursada de la asignatura Programación Web I. El objetivo principal fue aplicar de manera práctica los conceptos teóricos abordados en cada unidad, integrando progresivamente HTML, CSS y JavaScript para construir una aplicación funcional, estructurada y escalable.

Desde la primera actividad obligatoria hasta la instancia final, el proyecto fue evolucionando desde una página web estática hacia una aplicación interactiva que permite visualizar productos, filtrar información, agregar y eliminar elementos de un carrito de compras y calcular el total de la compra. Asimismo, se incorporaron conceptos de asincronía, manipulación del DOM, manejo de eventos y consumo de datos en formato JSON, respetando buenas prácticas de desarrollo web.

El proyecto fue versionado utilizando Git y GitHub, aplicando un flujo de trabajo basado en ramas (`master`, `develop` y `feature`), tal como se solicitó durante la cursada.

---

## Evolución del proyecto por actividades

### Actividad Obligatoria N°1 – Estructura inicial

En la primera entrega se desarrolló la estructura base del sitio web utilizando HTML5. Se definieron las secciones principales de la página, aplicando etiquetas semánticas como `header`, `main`, `section` y `footer`, con el objetivo de mejorar la accesibilidad y el posicionamiento SEO.

En esta etapa, la aplicación no presentaba interactividad, pero se dejó planificada la estructura necesaria para incorporar estilos y funcionalidades en entregas posteriores. Se priorizó una correcta organización del contenido y el uso adecuado de elementos como listas, enlaces, tablas y formularios.

---

### Actividad Obligatoria N°2 – Maquetación y estilos CSS

En la segunda entrega se incorporaron hojas de estilo CSS para mejorar la presentación visual del sitio. Se aplicaron conceptos fundamentales de diseño web, tales como el modelo de caja (box model), márgenes, padding y tipografías.

Asimismo, se comenzó a trabajar con sistemas de maquetación modernos como Flexbox y Grid, permitiendo organizar los elementos de forma responsive. Se implementaron media queries para adaptar la visualización a distintos tamaños de pantalla, siguiendo un enfoque de diseño adaptable.

---

### Actividad Obligatoria N°3 – Lógica en JavaScript

En la tercera entrega se introdujo JavaScript para agregar lógica y dinamismo a la aplicación. Se definieron variables, estructuras de control, funciones y objetos, permitiendo simular procesos internos del sistema.

En esta instancia se comenzó a modelar la lógica del negocio, preparando la base para funcionalidades más complejas, como la gestión de productos y el carrito de compras. El código JavaScript se organizó en archivos separados, manteniendo una correcta separación de responsabilidades.

---

### Actividad Obligatoria N°4 – DOM, eventos y almacenamiento

En la cuarta entrega se incorporó la manipulación del DOM y el manejo de eventos del usuario. Se definieron eventos como `click`, `input` y `DOMContentLoaded` para responder a las acciones del usuario en tiempo real.

Además, se implementó el uso de JSON y la asincronía mediante `fetch` y `async/await`, permitiendo cargar productos desde archivos externos sin recargar la página. Esto marcó un punto clave en la evolución del proyecto, transformándolo en una aplicación web dinámica.

También se trabajó con notificaciones visuales mediante librerías externas, mejorando la experiencia de usuario al mostrar mensajes de error y confirmación.

---

### Estado actual del proyecto

En su versión actual, la aplicación funciona como un simulador de e-commerce que permite:

- Cargar productos desde archivos JSON de manera asíncrona.
- Visualizar productos en una tabla dinámica.
- Filtrar productos por precio y texto.
- Agregar y eliminar productos de un carrito de compras.
- Calcular el total de la compra en tiempo real.
- Mostrar mensajes al usuario mediante alertas visuales.
- Mantener una estructura modular utilizando clases y módulos JavaScript.

El proyecto refleja la integración de los contenidos abordados durante la cursada, aplicando conceptos fundamentales del desarrollo web moderno y respetando buenas prácticas tanto en el código como en la organización del repositorio.

## Stack tecnológico

La aplicación fue desarrollada utilizando el siguiente stack tecnológico:

- **HTML5:** para la estructura semántica del sitio.
- **CSS3:** para la presentación visual, utilizando Flexbox, Grid y media queries.
- **JavaScript :** para la lógica de la aplicación, manipulación del DOM, eventos y asincronía.
- **JSON:** para el manejo de datos externos.
- **Git y GitHub:** para el control de versiones y trabajo con ramas.
- **GitHub Pages:** para la publicación del sitio web.
- **Librerías externas:** SweetAlert2 para notificaciones visuales.
