# Changelog

Este archivo documenta la evolución del proyecto a lo largo de las distintas actividades obligatorias realizadas durante la cursada de Programación Web I.

## [Actividad Obligatoria N°4] – DOM, eventos y asincronía

### Added
- Implementación de manejo de eventos del DOM (`click`, `input`, `DOMContentLoaded`).
- Carga de datos desde archivos JSON utilizando `fetch` y `async/await`.
- Integración de notificaciones visuales mediante librerías externas.

### Changed
- Refactorización de la lógica JavaScript para separar responsabilidades.
- Mejora en la interacción del usuario con la aplicación sin recarga de página.

### Fixed
- Correcciones menores en validaciones de entrada y manejo de errores.

---

## [Actividad Obligatoria N°3] – Lógica en JavaScript

### Added
- Incorporación de lógica de negocio utilizando JavaScript.
- Uso de variables, funciones, estructuras de control y objetos.
- Modelado inicial del carrito de compras y gestión de productos.

### Changed
- Organización del código JavaScript en archivos separados.
- Mejora en la claridad y mantenimiento del código.

---

## [Actividad Obligatoria N°2] – Maquetación y estilos CSS

### Added
- Implementación de estilos CSS para mejorar la presentación visual.
- Uso del modelo de caja (box model), márgenes, padding y tipografías.
- Aplicación de Flexbox y Grid para la maquetación del sitio.
- Incorporación de media queries para diseño responsive.

### Changed
- Adaptación del diseño a distintos tamaños de pantalla.
- Mejora de la experiencia visual y usabilidad.

---

## [Actividad Obligatoria N°1] – Estructura inicial del proyecto

### Added
- Creación de la estructura base del sitio utilizando HTML5.
- Uso de etiquetas semánticas (`header`, `main`, `section`, `footer`).
- Organización inicial del contenido del sitio.

### Changed
- Definición de una base sólida para la incorporación de estilos y funcionalidades futuras.
